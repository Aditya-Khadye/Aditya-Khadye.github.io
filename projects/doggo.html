Code walkthrough
Why this code

SiglipForImageClassification is a CLIP-family model fine-tuned for visual classification rather than contrastive captioning. CLIP-family models have strong visual representations out of the box — the fine-tuned Dog-Breed-120 checkpoint achieves high accuracy without any training code on our end.

logits.argmax(-1) is deterministic inference, not sampling. For a classification task where you want the most probable label — not creative variation — temperature sampling would only add noise. Separating load_model() from predict() is deliberate: the caller can load the 400MB+ weights once at startup and reuse the returned (processor, model, labels) tuple across many inference calls without reloading.

Why this code

Streamlit re-runs the entire script on every interaction. The get_model() wrapper exists so a future @st.cache_resource decorator can be added in one line — without it, the 400MB model would re-load on every file upload. The function call also makes testing straightforward: mock get_model and the rest of the app logic is testable in isolation.

image.convert("RGB") before inference is not optional. PNG files with transparency are RGBA (4 channels); JPEG files are RGB (3 channels). The Siglip processor expects 3-channel input — passing an RGBA tensor would silently produce wrong results or crash. The convert("RGB") call normalizes both cases before they reach the model.
